# 0002：早期文字绘制使用 LiteOS 的 12x24 A8 字体

早期图形输出直接复用 LiteOS 的 12x24 A8 ASCII 字体数据（0x20..0x7e，共 95 个 glyph，每个 glyph 288 字节）。

绘制接口直接写 UEFI GOP 提供的线性 framebuffer，不依赖字体解析器、文件系统或动态内存：

- `fb_draw_char_a8()` 绘制单字符。
- `fb_draw_text_a8()` 绘制字符串，并处理换行、回车和 4 字符宽 tab。
- 输入颜色统一为 `0x00RRGGBB`。
- A8 coverage 使用整数 alpha blend；0 完全背景，255 完全前景。
- 支持 UEFI GOP RGBR、BGRR 和 PixelBitMask；PixelBltOnly 不支持直接 framebuffer 写入。
- glyph 超出屏幕时裁剪，不越界。

字体数据保持为编译期只读表，不做运行时缓存或转换。后续如果 console 需要滚屏/dirty rows，再在这个最小绘制层之上增加终端状态，不把终端逻辑塞进字体 renderer。
